Runtime data used by Varscope.

Files:
- default.varscope.json: UI/session defaults
- saved_presets.json: user-saved probe presets
- sessions/: captured SQLite session files

Environment variables:
- VARSCOPE_OPENOCD: absolute path to openocd executable
- VARSCOPE_SHOW_BUILTIN_PRESETS: set to 1/true/yes/on to expose repo presets
